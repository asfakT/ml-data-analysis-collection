## 🛠️ Main Core Technologies Used

* **Programming Language:** Python
* **Data Management:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning Pipelines:** Scikit-Learn (Algorithms, Imputers, Encoders, Metrics)
* **Interactive Architecture:** Jupyter Notebook, Google Colab

---

## 📈 High-Level Workflow Summary

1. **Data Preprocessing & Cleaning:** Handled structural defects, eliminated unexpected null/zero artifacts via statistical imputation strategies, and vectorized text datasets.
2. **Exploratory Data Analysis (EDA):** Conducted correlation matrix mapping, pair plotting, and cluster profiling to extract core data distributions.
3. **Model Selection & Engineering:** Evaluated diverse algorithmic families including Gaussian Naive Bayes, Support Vector Machine (SVM), Linear Regression, Random Forest, Gradient Boosting, and Voting Classifiers.
